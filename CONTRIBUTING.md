# 🤝 Guía de Contribución - KoraDevs

¡Gracias por donar tu talento a KoraDevs! Para mantener el orden entre los desarrolladores, seguimos estas reglas:

---

### 1. ¿Quieres proponer una nueva app?
- Abre un **Issue** usando la plantilla oficial `🚀 Propuesta de Nueva Aplicación`.
- Una vez revisada la idea, se creará el repositorio exclusivo para esa aplicación dentro de @KoraDevsOrg y se te asignará como líder del proyecto.

---

### 2. Reglas de ramas (Branching)
- **NUNCA** hagas push directo a `main`.
- Nombra tus ramas según el tipo de cambio:
  - Funcionalidades nuevas: `feature/modulo-login`, `feature/calculadora`
  - Corrección de errores: `fix/error-pantalla`, `fix/calculo-total`
  - Documentación: `docs/manual-usuario`

---

### 3. Pull Requests (PRs)
- Cuando termines tu código, crea un **Pull Request** hacia `main`.
- Describe brevemente qué cambios hiciste.
- Solicita revisión al equipo (`@KoraDevsOrg/reviewers`).
- Se necesita al menos **1 aprobación** para hacer merge.
